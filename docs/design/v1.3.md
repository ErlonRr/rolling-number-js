# rolling-number v1.3: final specification

Status: **frozen for implementation** (revision 2, after the implementation-readiness review; see §15). This document is the single source of truth for v1.3.
Base: `feat/v1.3` at `672ca78` (v1.2.2 content, 189 tests).
Inputs: designs A (compat-lean) and B (quality-api), their two adversarial critiques, `docs/AUDIT.md` §3 and §5, and a re-verification prototype (§14).
Audience: engineers and AI agents implementing the work packages in §3. Every interface in §2 and §3.3 is normative: copy it verbatim.

v1.3 is a **minor** release. It is additive for the documented public API, option names and defaults, export paths, the `<rolling-number>` tag, the documented CSS classes and the CSS variables. The visual changes listed in §12.1 are intended because they fix audit bugs. No v2.0 item (the `.rn-root` subtree, removing `role="img"`, `::before` strips, a pure root entry, removing the `-input` heuristic, reconnect semantics) is pulled in.

These are the only places where v1.3 changes observable 1.x behavior beyond bug fixes. Each has a ready 1.x-compatible fallback. Implementation proceeds with the **default**.

## 1. Decisions

| # | Topic | Decision | Source | Why |
|---|---|---|---|---|
| 1 | Engine | One JS rAF engine drives both count (`interpolate:true`) and roll (`interpolate:false`). No CSS transitions on digits, sign or tokens. | A+B | Forward wraps, the Promise and events need JS timing; `page.clock` can then drive every pixel in tests |
| 2 | Count math | Windowed-carry odometer plus speed-limited reels (§5.3). | B | A's strict carry snaps digit-to-digit on large deltas (crit-A M13) |
| 3 | Start / retarget continuity | Every plan starts from the **displayed** channels through a remap: affine for monotone plans, a decaying offset otherwise; a reel stays a reel (§5.5). | crit-B H1 + new | B's additive offset rolled columns backward; B also jumped at the first frame when starting from rest (found in §14) |
| 4 | Retarget velocity | Cubic Hermite progress with start slope `s = clamp(v·D/ΔA, −1, 3)`. | B | Monotone for s ≤ 3; `s = 3` is exactly easeOutCubic. A's bump term goes backward (crit-A H1) |
| 5 | Sign and overflow | Fade windows scale with speed (`τ_s = 100 ms`). The overflow is driven on the **clamped** scalar. | crit-B H2 + new | A one-unit window pops (crit-B). An unclamped scalar gave 4 cells per frame on `95→150, max 99` (§14) |
| 6 | Wrap cell | `.rn-scale::after`, `position:absolute; top:100%`. Exactly 10 `.rn-cell`; the 1.2 `translateY(-N*10%)` rules are kept verbatim. | crit-A H5 + B | A pinned 1.2 stylesheet still renders correctly (verified). `textContent` is unchanged |
| 7 | Position | Inline `transform` on `.rn-scale` while moving; `data-digit` rules at rest. | new | Only one node is invalidated per column per frame (crit-B L4). The 1.2 CSS stays valid |
| 8 | Stable width (I07) | `.rn-col` is `inline-grid`: sizer and scale share one cell. The sizer keeps the digit text. | B, crit-A LOW | Width = widest glyph (verified with proportional fonts). Sizer scrapers keep working |
| 9 | Enter/leave | JS-driven `--rn-in` × `--rn-w`. Nodes are inserted **collapsed synchronously**. `--rn-w` comes from a reference column (digits) or a `Range` (text tokens). | B + crit-B H4 + new | No one-frame flash; no measurement of collapsed nodes (verified) |
| 10 | Timing source | Priority: per call → option → **non-default** CSS var → path default. CSS is read via `getComputedStyle(sizer).animationDuration/TimingFunction` (§5.8). | B + crit-B H5 | The browser resolves `calc()` and normalizes easings. Works in shadow roots (verified) |
| 11 | `duration` typing | Stays `duration?: number`. "Unset" is expressed by `undefined`/`null` through `RollingNumberUpdate`. | B | The public field type is unchanged |
| 12 | `decimals` | Default *auto*: Intl currency digits, else 0. | B, crit-A H4 | `format: currency` must not lose its cents |
| 13 | `format` | Discriminated union keyed on `style`. Element attribute takes JSON. | B | Typing is a top priority: `currency` requires `currency` |
| 14 | Affix names | `prefixText` / `suffixText` everywhere (attributes `prefix-text` / `suffix-text`). | crit-A H2 | `Element.prototype.prefix` is a read-only getter, so React 19 throws before upgrade |
| 15 | Angular inputs | Every v1.3 input is `rn` + PascalCase option name. Legacy inputs also get `rn*` aliases. | crit-A H3, crit-B H6 | PrimeNG `p-inputNumber` has `prefix/suffix/mode/format/locale/max` |
| 16 | Promise | `setValue → Promise<RollingNumberSettled>` (never rejects) plus `whenSettled()` (S1). | B shape | Typed, self-describing result |
| 17 | Events | `rn-start` / `rn-end`, one detail type, bubbles + composed. The CustomEvent is delivered in every adapter. Instant changes dispatch in a microtask. `ElementEventMap` augmentation. | A+B+critics | One rule for agents. No re-entrancy into framework patching |
| 18 | SSR | Opt-in text fallback `<span class="rn-ssr" data-rn-ssr>` showing the formatted `value`. It is hidden (not removed) at mount. | B + crit-A H6 + crit-B H3a/M2 | Readable without CSS, safe for hydration, not breaking |
| 19 | Text mode | `auto` → text for text-like `input`, `textarea`, `option` (`.text`), SVG text. Roll = count with roll timing. Writes skip focused controls; the blur write is guarded. | A+B+critics | "Animation works in every tag"; never fight the user or the form |
| 20 | `trigger` | `'immediate' \| 'visible'`. `visible` gates every animation while off-screen. The element remembers that the intro was consumed. | A + crit M3/M11 | More useful than intro-only; no replay on DOM moves |
| 21 | Live region | One ref-counted region per container (each `dialog`/`[aria-modal="true"]` element, plus `body`), per-host debounce 300 ms inside `a11y.ts`, styled through CSSOM. | A + crit-A M10 + spec review | Works in modals and under CSP; body counters never announce into a closed modal |
| 22 | Style injection | `adoptedStyleSheets` per root in `@layer rolling-number`, with `@layer` and constructable-sheet feature detection, one sheet per realm, an `includes()` check, global config through `Symbol.for`. `dist/style.css` stays unlayered with `:root` defaults. | A+B+crit-A M6 | |

## 2. Public API (normative)

### 2.1 `src/types.ts` (new; types only, re-exported by every entry listed in §2.8)

```ts
/** Named easings. CSS keywords map to their cubic-bezier; `ease-out-cubic` is the 1.x count curve; `odometer` = cubic-bezier(0.2, 1, 0.3, 1), the 1.x roll curve and the `--rn-easing` default. */
export type RollingNumberEasingName =
  | 'linear' | 'ease' | 'ease-in' | 'ease-out' | 'ease-in-out'
  | 'ease-out-cubic' | 'ease-in-out-cubic' | 'ease-out-quart' | 'ease-out-expo' | 'odometer';

/**
 * Easing of an animation: a preset, a CSS easing string (`cubic-bezier(x1, y1, x2, y2)` with x1, x2 in [0, 1],
 * `linear(…)`, `steps(…)`), or a function mapping progress [0, 1] → [0, 1] (must return 0 at 0 and 1 at 1; may overshoot:
 * overshoot bounces the digits when rolling and is flattened at the endpoints when counting).
 * Invalid strings fall back to the default with a one-time console warning.
 */
export type RollingNumberEasing =
  | RollingNumberEasingName
  | `cubic-bezier(${string})` | `linear(${string})` | `steps(${string})`
  | ((progress: number) => number);

/** How the value is drawn. `auto`: `text` for text-like `<input>`, `<textarea>`, `<option>` and SVG `<text>`/`<tspan>`/`<textPath>`; `columns` otherwise. */
export type RollingNumberMode = 'auto' | 'columns' | 'text';
/** `immediate`: animate as soon as the value changes. `visible`: animations wait until ≥25% of the host is in the viewport. */
export type RollingNumberTrigger = 'immediate' | 'visible';
/** Opt-in screen-reader announcement of the settled value through a shared live region. */
export type RollingNumberLive = 'off' | 'polite' | 'assertive';

/** Intl options common to every `format.style`. The locale is the top-level `locale` option; fraction digits are `decimals`. */
export interface RollingNumberFormatBase {
  /** Group separators (`1,234`). Default when Intl formatting is on: Intl's default (`'auto'`). */
  useGrouping?: boolean | 'always' | 'auto' | 'min2';
  /** Sign policy. `'always'` shows `+` on positives; `'never'` hides the sign. @default 'auto' */
  signDisplay?: 'auto' | 'never' | 'always' | 'exceptZero' | 'negative';
  /** Numbering system for native digits, e.g. `'arab'`, `'deva'`, `'thai'`. Default: the locale's. */
  numberingSystem?: string;
}
/** Sanctioned Intl units (autocompleted); any string is still accepted. */
export type RollingNumberUnit =
  | 'percent' | 'second' | 'minute' | 'hour' | 'day' | 'week' | 'month' | 'year'
  | 'bit' | 'byte' | 'kilobyte' | 'megabyte' | 'gigabyte' | 'terabyte'
  | 'meter' | 'kilometer' | 'centimeter' | 'mile' | 'foot' | 'inch'
  | 'gram' | 'kilogram' | 'pound' | 'liter' | 'milliliter' | 'celsius' | 'fahrenheit' | 'degree'
  | 'kilometer-per-hour' | 'mile-per-hour' | 'meter-per-second'
  | (string & {});
/**
 * Intl number formatting, discriminated by `style`: `currency` requires `currency`, `unit` requires `unit`.
 * Setting `format` or `locale` switches on Intl formatting; otherwise output is the 1.x plain format.
 */
/** Keys that belong to another `style`; `never` makes `{ currency: 'EUR' }` without `style: 'currency'` a type error. */
interface RollingNumberNoCurrency { currency?: never; currencyDisplay?: never; currencySign?: never; }
interface RollingNumberNoUnit { unit?: never; unitDisplay?: never; }
export type RollingNumberFormat =
  | (RollingNumberFormatBase & RollingNumberNoCurrency & RollingNumberNoUnit & { style?: 'decimal' })
  | (RollingNumberFormatBase & RollingNumberNoCurrency & RollingNumberNoUnit & { style: 'percent' })   // 0.25 → "25%"
  | (RollingNumberFormatBase & RollingNumberNoUnit & {
      style: 'currency';
      /** ISO 4217 code, e.g. `'EUR'`. */ currency: string;
      currencyDisplay?: 'symbol' | 'narrowSymbol' | 'code' | 'name';
      currencySign?: 'standard' | 'accounting';
    })
  | (RollingNumberFormatBase & RollingNumberNoCurrency & {
      style: 'unit';
      /** Sanctioned unit or `a-per-b`, e.g. `'kilometer-per-hour'`. */ unit: RollingNumberUnit;
      unitDisplay?: 'short' | 'narrow' | 'long';
    });

/** Argument of a `label` function. */
export interface RollingNumberLabelInfo {
  /** Formatted target as text, with affixes, unclamped by `max` (e.g. `"$1,234.50"`, `"150"`). */ text: string;
  /** Normalized target value. */ value: number;
  /** `true` when `|value| > max` (the display is clamped and shows `overflowSuffix`). */ overflow: boolean;
}

/** Per-call overrides of `setValue`. */
export interface RollingNumberSetValueOptions {
  /** `'count'`: count through the values; `'roll'`: each digit rolls straight to its new digit; `'none'`: instant. Default: from `interpolate`. */
  motion?: 'count' | 'roll' | 'none';
  /** Duration of this change in ms (`0` = instant). */ duration?: number;
  /** Easing of this change. */ easing?: RollingNumberEasing;
}
/** Resolution of `setValue()` / `whenSettled()`. Never rejects. */
export interface RollingNumberSettled {
  /** The target this promise was waiting for. */ value: number;
  /** `true`: the display settled on `value`. `false`: superseded by another target, or `destroy()`. */ completed: boolean;
}

/** `detail` of `rn-start` and `rn-end`. */
export interface RollingNumberEventDetail {
  /** Target value of the motion (normalized). */ value: number;
  /** Value on screen when the motion started (user units, may be fractional). */ from: number;
  /** `false` for instant changes (reduced motion, `motion: 'none'`, duration 0, no rAF). */ animated: boolean;
}
export type RollingNumberEvent = CustomEvent<RollingNumberEventDetail>;
export interface RollingNumberEventMap {
  /** The display starts moving from rest (also for instant changes). Not re-fired on retargets. */ 'rn-start': RollingNumberEvent;
  /** The display settled on the final target; DOM is final, promises resolve right after. */ 'rn-end': RollingNumberEvent;
}
declare global {
  // Typed listeners on any host, HTML or SVG: el.addEventListener('rn-end', (e) => e.detail.value)
  interface ElementEventMap extends RollingNumberEventMap {}
}

/** Global configuration (`configureRollingNumber`). Shared across ESM/CJS copies of the package. */
export interface RollingNumberConfig {
  /** Inject the stylesheet into every Document/ShadowRoot that hosts a counter. @default true */
  injectStyles?: boolean;
  /** CSP nonce for the `<style>` fallback (only where constructable stylesheets are unavailable). @default null */
  nonce?: string | null;
}
```

### 2.2 `RollingNumberOptions` (in `src/types.ts`; `src/core.ts` re-exports it)

The 1.x fields keep their names, types, defaults and normalization. JSDoc must be copied with the semantics below.

```ts
export interface RollingNumberOptions {
  // ── 1.x ───────────────────────────────────────────────────────────
  /** Target value. Non-finite → 0. Magnitude clamped to MAX_SAFE_INTEGER, and further to MAX_SAFE_INTEGER / (scale·10^decimals) when decimals/percent are used. Rounded half away from zero to the displayed precision. @default 0 */
  value?: number;
  /** Minimum integer digits (leading zeros), 1..64. Past 21 with Intl formatting, the extra zeros are prepended without group separators. @default 1 */
  pad?: number;
  /** Upper bound of the displayed magnitude (after percent scaling), floored to `decimals` places. `null`/''/negative/non-finite → no limit. The label keeps the real value. @default null */
  max?: number | null;
  /** `true`: count through intermediate values (continuous odometer). `false`: each digit rolls straight to its new digit. Reduced motion → instant. @default true */
  interpolate?: boolean;
  /**
   * Duration of animated changes, in ms.
   * - unset: counting uses 400 and rolling uses `--rn-duration` (0.5s); a non-default `--rn-duration` drives both;
   * - `> 0`: used for counting **and** rolling;
   * - `0`: no counting (1.x meaning); the change rolls with the CSS timing.
   * Negative → 0. Non-finite at creation → unset; in `setDuration`/`update` a non-finite number keeps the current value and `null` resets to unset.
   * @default 400 (effective counting duration when unset)
   */
  duration?: number;

  // ── 1.3 ───────────────────────────────────────────────────────────
  /** Easing of animated changes. Unset: `'ease-out-cubic'` when counting and `--rn-easing` (default `'odometer'`) when rolling; a non-default `--rn-easing` drives both. */
  easing?: RollingNumberEasing;
  /** Fixed fraction digits, 0..20. Unset: the currency's digits with `format.style: 'currency'`, else 0. */
  decimals?: number;
  /** BCP 47 locale(s). Setting `locale` or `format` switches on Intl formatting (separators, native digits, affixes). Invalid → runtime default locale (warning). */
  locale?: string | readonly string[];
  /** Intl number formatting. See {@link RollingNumberFormat}. */
  format?: RollingNumberFormat;
  /** Static text before the number (and before the sign), rendered as text. Included in the label. @default '' */
  prefixText?: string;
  /** Static text after the number. Included in the label. @default '' */
  suffixText?: string;
  /** Shown right after the digits when |value| > `max`, e.g. `'+'` → "99+". Ignored when `max` is null. @default '' */
  overflowSuffix?: string;
  /** Renderer. Changing it at runtime finishes the current motion and re-creates the renderer. @default 'auto' */
  mode?: RollingNumberMode;
  /** Value shown at creation; the counter then animates to `value` (respecting `trigger`). Creation-only. Skipped when an SSR fallback (`[data-rn-ssr]`) is adopted and the host is visible, so server-rendered content never regresses. @default null */
  from?: number | null;
  /** When animations may run. @default 'immediate' */
  trigger?: RollingNumberTrigger;
  /** Accessible name in columns mode: a string where `{value}` is replaced by the formatted target, or a function. Default: the target (1.x), formatted when formatting options are set. */
  label?: string | ((info: RollingNumberLabelInfo) => string);
  /** Announce each settled value through a shared live region (debounced 300 ms). @default 'off' */
  live?: RollingNumberLive;
  /** Per-instance switch for automatic style injection (the global `configureRollingNumber({ injectStyles: false })` wins). @default true */
  injectStyles?: boolean;
}

/** Options accepted by the constructor and `update()`: `undefined` = unchanged (update) / default (constructor), `null` = reset to the default. */
export type RollingNumberUpdate = { [K in keyof RollingNumberOptions]?: RollingNumberOptions[K] | null };
```

### 2.3 `RollingNumberCore` (changes only; everything else is 1.2.2)

```ts
export class RollingNumberCore {
  /** @param container Any element. Container hosts get columns; form controls and SVG text get text mode (see `mode`). @throws when not an element. */
  constructor(container: HTMLElement | SVGElement, options?: RollingNumberUpdate);
  /**
   * Sets the target. `animate`: boolean (1.x: true = count, false = roll) or per-call options.
   * Resolves when this target settles (`completed: true`), or when it is superseded or the core is destroyed (`completed: false`).
   * Setting the target already in flight with no explicit motion change joins that motion (same promise outcome, no events);
   * an explicit instant request (`motion: 'none'`, `duration: 0`) finishes it, an explicit kind/duration/easing change re-plans it (§8.2). Never rejects.
   */
  setValue(value: number, animate?: boolean | RollingNumberSetValueOptions): Promise<RollingNumberSettled>;
  /** Same as 1.x plus every 1.3 field; `null` resets a field to its default. */
  update(options: RollingNumberUpdate): void;
  /** Resolves when the current motion settles (immediately when idle). */
  whenSettled(): Promise<RollingNumberSettled>;
  /** Jumps to the target now: final DOM, `rn-end`, pending promises resolve `completed: true`. No-op when idle. */
  finish(): void;
  /** Value on screen (signed, user units; fractional mid-count). */
  getDisplayValue(): number;
  /** Displayed text of the target at rest: clamped by `max`, with `overflowSuffix` and affixes, e.g. "$1,234.50", "99+" (what text mode shows). The unclamped text is in the default label / `RollingNumberLabelInfo.text`. */
  getText(): string;
  /** Renderer in use after `auto` resolution. */
  getMode(): 'columns' | 'text';
  /** The host as passed to the constructor (accurately typed). `getElement()` keeps returning `HTMLElement` for 1.x compatibility. */
  getHost(): HTMLElement | SVGElement;
  /** Now also true while rolling (S3). */
  isAnimating(): boolean;
  /** Widened from `number`: `null` resets to unset (S2); a non-finite number keeps the current value (1.x). */
  setDuration(duration: number | null): void;
  // unchanged: render(), getValue(), getElement(), setInterpolate(), setPad(), setMax(), destroy()
}
/** Global configuration. Call before the first counter is created; later calls apply to roots injected afterwards. */
export function configureRollingNumber(config: RollingNumberConfig): void;
/** Manually inject the stylesheet into a root (for `injectStyles: false` setups, or to pre-warm a shadow root). Idempotent. */
export function injectRollingNumberStyles(root: Document | ShadowRoot): void;
```

`setDuration(null)` resets to unset (S2). `setDuration(NaN)` keeps the current value (1.x). Widening a parameter is non-breaking for callers; a subclass overriding `setDuration(d: number)` still type-checks (method bivariance).

`RN_DEFAULTS` and `normalizeOptions` stay exported from `src/core.ts` (reachable through `dist/core.d.ts`) with their exact 1.2 signatures and 5-field values (frozen; non-finite duration → 400). They are compatibility shims; 1.3 code uses `RN_DEFAULTS_13`/`resolveOptions` from `options.ts` (§3.3).

### 2.4 Events

| name | detail | bubbles | composed | cancelable | fired |
|---|---|---|---|---|---|
| `rn-start` | `RollingNumberEventDetail` | yes | yes | no | Animated: in the post phase of the motion's first frame. Instant change: in a microtask after `setValue`, followed by `rn-end`; a roll made instant by a CSS `0s` duration: in the post phase of its first frame, followed by `rn-end` (§5.8). Not fired on retargets, re-plans or joins. |
| `rn-end` | same (`value` = settled target) | yes | yes | no | After the settle frame: DOM final, animating markers removed. Promises resolve after dispatch. Once per motion session. |

- Events are dispatched on the core's host (the form control in text mode).
- `destroy()` dispatches nothing.
- The initial render dispatches nothing, except the `from → value` intro.
- Under reduced motion both events still fire with `animated: false`.
- Calling `setValue` from a handler is safe: state is committed before dispatch.

### 2.5 `<rolling-number>` attributes, properties and methods

| `label` | `label` | `string \| ((i) => string) \| null` | function: not reflected |
| `live` | `live` | `RollingNumberLive` | |
| `inject-styles` | `injectStyles` | `boolean` | `"false"` opts out |

- **Absent means unset (S5, normative).** `readOptions()` and `attributeChangedCallback` pass `null` for an absent or removed `duration`/`easing` attribute, never `RN_DEFAULTS.duration`. `value`, `pad`, `max`, `interpolate` keep their 1.2 default mapping; absent 1.3 attributes map to `null` (= default through `resolveOptions`). Attribute names come from `OPTION_ATTRIBUTES` (§3.3).
- **Internal state** is read only through `getResolved(core)` (§3.3); the 1.2 `getCoreDuration` helper is removed.

Methods:
- `setValue(v, o?)`: stashes `o`, reflects `value`, then **clears the stash unconditionally**. If `attributeChangedCallback` consumed the stash it returns the promise that call produced. If not (the attribute string was unchanged, so the callback returned early) it calls `core.setValue(v, o)` directly and returns that promise. Disconnected → resolves `{ value, completed: false }`.
- `whenSettled()`, `finish()`, `getDisplayValue()` delegate to the core.

The element fires `rn-start`/`rn-end`.

`RollingNumberAttributes` (used by the JSX and Vue element typings) gains every attribute above in its attribute form, e.g. `decimals?: number | \`${number}\` | null`, `'no-interpolate'?: boolean | '' | null`, `format?: RollingNumberFormat | string | null`, `easing?: RollingNumberEasing | null`.

  RollingNumberEasing, RollingNumberFormat, RollingNumberLabelInfo, RollingNumberLive,
  RollingNumberMode, RollingNumberOptions, RollingNumberSetValueOptions, RollingNumberTrigger

// ── options.ts ────────────────────────────────────────────────────────
/** Fully normalized options. `null` = "auto/unset" where the public API allows it. */
export interface NormalizedOptions {
  value: number; pad: number; max: number | null; interpolate: boolean;
  duration: number | null;                 // null = auto (count 400 / roll CSS)
  easing: RollingNumberEasing | null;      // null = auto
  decimals: number | null;                 // null = auto (currency digits or 0)
  locale: readonly string[] | null;
  format: RollingNumberFormat | null;
  prefixText: string; suffixText: string; overflowSuffix: string;
  mode: RollingNumberMode; from: number | null; trigger: RollingNumberTrigger;
  label: string | ((info: RollingNumberLabelInfo) => string) | null;
  live: RollingNumberLive; injectStyles: boolean;
}
export type OptionKey = keyof RollingNumberOptions;
// options.ts exports (all internal):
// RN_DEFAULTS_13: Readonly<NormalizedOptions>     (frozen; duration/easing/decimals/locale/format/label = null)
// OPTION_KEYS (§2.7);  OPTION_ATTRIBUTES: Readonly<Record<OptionKey, string>>   // prefixText → 'prefix-text', …; used by element.ts and ssr.ts
// resolveOptions(o: RollingNumberUpdate | null | undefined): NormalizedOptions   // constructor semantics; non-finite duration → null
// normalizeField<K extends OptionKey>(key: K, raw: unknown, current: NormalizedOptions): NormalizedOptions[K]   // update() semantics
// LAYOUT_KEYS = ['pad','max','decimals','locale','format','prefixText','suffixText','overflowSuffix','mode'] as const

- **New public hooks:** `.rn-static[data-rn-part]`, `data-rn-key`, `data-rn-lead`, `data-rn-in` + `--rn-in`/`--rn-w` (read-only), `data-rn-zero`, `.rn-ssr[data-rn-ssr]`.

- **Keys** (from format.ts):
  - integer digits `i{j}`, j counted from the right (units = `i0`);
  - fraction digits `f{j}`, j counted from the left (tenths = `f1`);
  - a group separator takes the place of the digit on its left (`g3` sits between `i3` and `i2`);
  - `dec`, `sign`, `pre`, `suf`, `ovf`, and `lit:pre:n`/`lit:post:n` for Intl literals/currency/unit/percent by side and occurrence.
- **Reconciliation:**
  - DOM order = the motion layout's token order. A node is moved only when its `nextSibling` differs.
  - An owned node missing from the motion layout (possible after a retarget) keeps its position relative to its neighbors, fades as leaving, and is removed only by `rest()`, never by `begin()` (§3.3).
  - The owned block is contiguous and appended after pre-existing children. Nodes the core does not own are never touched.
  - Keyed identity fixes B18: on 99 → 100, the `i0`/`i1` nodes stay and `i2` enters on the left.
- **`data-digit`:**
  - Roll path: set to the **target** digit synchronously in `setValue` (1.2 compatibility).
  - Count path: `round(pos) mod 10` per column, written only when it changes. Mid-count the columns do not form a coherent number (S6); use `getDisplayValue()`.
  - At rest: the final digit. The sizer text is written at rest only.
- **Inline styles exist only while moving:** `transform` on `.rn-scale`, `--rn-in`/`--rn-w` on entering/leaving nodes. `rest()` removes them, and removes the `style` attribute when it becomes empty.
- **Sign:** a real text node holding `−` (U+2212) on the plain path, or Intl's `minusSign`/`plusSign`. It exists while the display is negative, during any motion with a negative endpoint, and always with `signDisplay: 'always'`. At rest with a positive value there is no `.rn-sign` node (1.2 tests). With `signDisplay: 'always'` the text swaps at A = 0.

### 4.2 Position and size mechanism

- **At rest:** `.rn-col[data-digit=N] > .rn-scale { transform: translateY(-N*10%) }`, the verbatim 1.2 rules. The percentage is relative to the scale's own height (10 cells), so the step is always exactly one cell (B20-proof).
- **Moving:** `scale.style.transform = 'translateY(' + (-10 * mod10(pos)).toFixed(3) + '%)'`. Positions in (9, 10) show the wrap cell `.rn-scale::after` (glyph 0), placed `position:absolute; top:100%` with the cell height. The scale keeps 10 in-flow cells, so a pinned 1.2 stylesheet still lays out correctly (§14.2).
- **Stable width:**
  - `.rn-col` is `inline-grid`; `.rn-col::before` (decorator), `.rn-sizer` and `.rn-scale` all sit in `grid-area: 1/1`. The track width is the widest of the sizer and the 10 cells, so it never depends on the current digit.
  - Every column of a counter has the same width, which makes it the reference width for entering columns.
- **Enter and leave:**
  - `[data-rn-in]` sets `width: calc(var(--rn-in,0) * var(--rn-w,0px)); opacity: var(--rn-in,0); overflow: clip`.
  - Entering nodes are inserted with `data-rn-in` and `--rn-in: 0` in `begin()`. Until measured they are collapsed (`--rn-w` falls back to `0px`).
  - In `measure()` (read phase): `--rn-w` for columns = the width of any present column; for text tokens (sign, separators, overflow, literals) = the width of a `Range` over the token's text, which is valid even while the box is collapsed (§14.2).
  - Leaving nodes measure their own box before collapsing.

## 5. Animation math (verified, §14)

### 5.1 Units

- `f` = fraction digits; `S` = 100 for percent, else 1.
- `A = quantize(v)`: a signed integer in last-digit units (§7.3).
- `Amax = floor(max·10^f)`, or ∞.
- Places `k = 0…n−1` (k = 0 is the last displayed digit); integer place `j = k − f`. `P_k = 10^k`.
- Clamped scalar: `cl(A) = sgn(A)·min(|A|, Amax)`. Every motion animates `cl`. Overflow presence at the endpoints: `o_i = |A_i| > Amax`.
- Plan: `A0 = cl(A0raw)`, `A1 = cl(A1raw)`, `M = |A(t)|`, `M0 = |A0|`, `M1 = |A1|`, `cross = A0·A1 < 0`.
- Progress: `p = clamp((now − t0)/D, 0, 1)`, where t0 is the first frame timestamp (B32).
  - Count plans: `q = clamp(E(p), 0, 1)` and `A(q) = A0 + (A1 − A0)·q`, so `A ∈ [min(A0,A1), max(A0,A1)]` and `|A| ≤ Amax` even with overshooting easings (`cubic-bezier` y outside [0, 1], functions). Without the clamp, 95→99 with a back-out easing reaches A = 99.39, needing a place the plan has no node for, and 0→5 with back-in flashes a minus sign. Overshoot on the count path is therefore flattened (documented on `RollingNumberEasing`).
  - Roll plans: `q = E(p)` unclamped for `pos` (a bounce past the target digit and back is allowed and passes through the wrap cell); `inn`, `sigma`, `ovf` are clamped to [0, 1].
- Constants: `τ = 40 ms`, `τ_s = 100 ms`, `V_MAX = 0.04 cells/ms`, `E'max = peakSlope(E)` (65 samples).

### 5.2 Count path: windowed-carry exact columns

```
X(m, k, W) = k = 0 ? m : ⌊m/P_k⌋ + clamp(1 − (P_k − (m mod P_k))/W, 0, 1)   // W = 1: classic gear; W = P_k: analog
v_peak  = |A1 − A0| · E'max / D                                             // units/ms
W_k     = clamp(v_peak · τ, 1, P_k)
gap1_k  = P_k − (M1 mod P_k)
R(t)    = cross ∧ sgn(A) = sgn(A0) ∧ A ≠ 0 ? M + M1 : |M1 − M|                // remaining path
W_eff   = clamp(min(W_k, gap1_k + R), 1, P_k)
exact_k = X(M, k, W_eff)
```

Properties (proven by B, re-checked numerically in §14):
- continuous in M;
- exact at the end (`W_eff ≤ gap1` when R = 0);
- monotone along M for non-crossing plans.

### 5.3 Count path: speed-limited reels

```
T_k = cross ? X(M0,k,1) + X(M1,k,1) : |X(M1,k,1) − X(M0,k,1)|     // true travel, cells
L   = V_MAX · D / E'max
reel_k ⇔ T_k > max(10, L)  ∨  (prevKind = 'count' ∧ display.reel[k])   // a reel stays a reel on retarget
dir = sgn(M1 − M0) || 1;   start = display.pos[k];   r = mod10(dir·(X(M1,k,1) − start))
nRev = was a reel ? max(0, ⌊(L − r)/10⌋) : clamp(⌊(L − r)/10⌋, 1, max(1, ⌊T_k/10⌋))
pos_k(q) = start + dir·(r + 10·nRev)·q
```

- Reels are a contiguous low-order set. They land exactly (`pos ≡ digit mod 10` at q = 1) and share q with the exact columns.
- **Speed bound** (cells per 16.7 ms frame): reels ≤ `(L + 20)·E'max·16.7/D`; exact columns ≤ `10·E'max·16.7/D`.
- With the defaults (400 ms, ease-out-cubic) the measured maxima are 1.73 (exact) and 2.08 (reels). Faster user timings scale proportionally; the worst random case is 4.9 with 200 ms ease-out-expo. Documented.

### 5.4 Lead, enter, sign, overflow

```
lead_k  = j ≥ pad ∧ M/10^f < 10^j          // integer places beyond pad that are currently leading zeros
inn_k   = lead_k ? clamp(exact_k, 0, 1) : 1  // width × opacity of the column (and of tokens tied to it)
W_s     = clamp(v_peak·τ_s, 1, min{|A_i| : A_i < 0, i ∈ {0,1}})          // only negative endpoints cap it
sigma   = A0 ≥ 0 ∧ A1 ≥ 0 ? 0 : clamp(−A / W_s, 0, 1)                   // ≡ 0 when neither endpoint is negative
ovf     = o0 = o1 ? o0
        : (dist = Amax − M_nonOverflowingEnd) < 1 ? o0 + (o1 − o0)·q
        : clamp((M − (Amax − W_o))/W_o, 0, 1),   W_o = clamp(v_peak·τ_s, 1, dist)
```

The caps make every channel exact at both endpoints. With `−50 → 50`, the sign fades over 5 frames (80 ms) instead of popping (crit-B H2).

### 5.5 Remap from the displayed state (start and retarget)

Every plan is anchored on what is on screen: `display` from `renderer.displayed()`, or `restState(A0)` when idle. Let `raw(q)` be the formulas above, `s0 = raw(0)`, `s1 = raw(1)`, and for each non-reel channel let `d0` be the displayed value (`pos`: `d0 = s0 + wrap5(display − s0)`).

```
remap(v, s0, s1, d0, q) =
  |d0 − s0| < 1e−9                 → v                                   // exact
  !cross ∧ |s1 − s0| > 1e−9        → s1 + (d0 − s1)·(1 − (v − s0)/(s1 − s0))   // affine: monotone if d0 is behind s0
  otherwise                        → v + (d0 − s0)·(1 − q)               // decaying offset
inn, sigma, ovf are clamped to [0, 1] after remap
```

- **Retarget `from` shape.** On a retarget the motion layout is `motionLayout(formatter.shapeOfDisplay(display), shapeOf(A1))`, never `shapeOf(round(A))`. `shapeOfDisplay` counts every place with `inn > 0`, a sign with `sigma > 0` and an overflow with `ovf > 0`, so half-collapsed leaving columns and a fading sign stay in the new layout and keep animating. Any owned node still missing from it follows the renderer rule of §3.3/§4.1 (fades, removed at rest).
- Starting from rest is now continuous. At speed, `X(M0, k, W)` can sit up to one cell ahead of the rest digit (e.g. `5 → 120`: tens planned at 0.5).
- The only backward motion that remains is a column that had partly carried toward a digit the new target never reaches. It is bounded at ≤ 1.05 cells cumulative over 2,788 random retargets (§14).

### 5.6 Retarget progress (count → count)

```
v   = (prev.A1 − prev.A0)·slopeAt(prev.E, pPrev)/prev.D          // units/ms at the retarget
ΔA  = cl(A1) − Anow;   D' = resolved duration of the new change    // both clamped: Anow is the clamped display scalar
if |ΔA| < 1e−9 ∨ v = 0: s = 0
else: s = v·D'/ΔA;  if s > 3: D' = max(0.4·D', 3·ΔA/v), s = min(3, v·D'/ΔA)
s   = clamp(s, −1, 3);   E = hermite(s):  H(p) = s(p³ − 2p² + p) + 3p² − 2p³
```

- `H` is monotone for s ∈ [0, 3]; s = 3 is exactly ease-out-cubic. s < 0 continues the old direction briefly, a dip of ≤ 5.3% on reversals.
- With an unclamped A1 (e.g. `max: 99`, retargeting 90→98 at p = 0.3 to 150), using A1 made s 14× too small and stalled the motion (prototype: start velocity 0.0020 vs 0.029 units/ms).
- From a roll, or from rest: the user easing, no velocity carry.
- **Join:** see §8.2 step 2 (a join is decided on the target **and** the per-call intent).

### 5.7 Roll path (`interpolate:false`, `motion:'roll'`, `duration: 0`)

```
dir_k  = sgn(M1 − M0), or per column sgn(wrap5(d1 − start)) when M1 = M0
pos_k  = start + dir·mod10(dir·(d1_k − start))·q              // forward 9 → 0 through the wrap cell (B19)
entering place: start 0, lead, inn = q; leaving: d1 = 0, lead, inn = 1 − q
sigma  = σ_display + (σ1 − σ_display)·q;  ovf likewise
```

A roll retarget restarts from the displayed positions with the roll easing (no momentum, the same as 1.2 CSS transitions). Count → roll and roll → count are both anchored by §5.5.

### 5.8 Timing resolution (`engine/timing.ts`)

```
flag   = typeof animate = 'boolean' ? animate : opt.interpolate          // an options object without `motion` follows `interpolate`
kind   = call.motion ?? (flag ? 'count' : 'roll')
if kind = 'count' ∧ opt.duration = 0 ∧ call.duration = undefined → kind = 'roll', ignore opt.duration (1.x "0 = no counting")
cssMissing ⇔ durationCss = '0s' ∧ easingCss = 'ease'                 // our rule is absent
cssD   = cssMissing ? null : parseCssTime(durationCss)               // probe values are browser-normalized
cssD   = kind = 'count' ∧ cssD = 0 ? null : cssD                     // a 0s / invalid --rn-duration only disables rolls (1.2 idiom, S4)
cssE   = cssMissing ? null : (easingCss = DEFAULT_CSS_EASING ? null : parseEasing(easingCss))
D      = call.duration ?? (opt.duration > 0 ? opt.duration : (cssD ≠ null ∧ cssD ≠ 500 ? cssD : kind = 'count' ? 400 : 500))
E      = call.easing ?? opt.easing ?? cssE ?? (kind = 'count' ? 'ease-out-cubic' : 'odometer')
instant ⇔ call.motion = 'none' ∨ D ≤ 0 ∨ reducedMotion ∨ no rAF
```

- **Synchronous vs read-phase instant.** `motion: 'none'`, `call.duration ≤ 0`, reduced motion, no rAF and `!renderer.canAnimate()` are known in `setValue` (§8.2 step 5). Only a CSS-derived `D = 0` (a roll with `--rn-duration: 0s`) is discovered in the first read phase. Then the write phase of that frame calls `renderer.rest(target)` and returns `true`, and the post phase dispatches `rn-start` then `rn-end`, both with `animated: false`, in that same frame. The promise resolves after `rn-end`.

- **Probe:** `getComputedStyle(firstSizer).animationDuration` / `.animationTimingFunction`. It is read once per motion in the ticker read phase; the core never writes `--rn-duration`/`--rn-easing` (I23).
- **Text mode** has no sizer, so it reads the raw `--rn-duration`/`--rn-easing` custom properties from the host and parses them; `calc()` is unsupported there (documented).
- **Quirk (documented):** an explicit `--rn-duration: 0.5s` counts as "default", so counting stays at 400 ms.

### 5.9 Frame pipeline (shared ticker, one rAF per window)

1. **read:** resolve timing and plan (first frame), and `renderer.measure()` when nodes were added.
2. **write:** `sample` → `renderer.frame` (or `renderer.rest` when p ≥ 1, which returns `true`).
3. **flush:** if any counter settled, run one `getComputedStyle(host).opacity` read. This protects users' or pinned-1.2 transitions from replaying (B17 order).
4. **settled:** remove `data-rn-state` and `.rn-interpolating`.
5. **post:** dispatch `rn-start` (first frame) / `rn-end`, resolve promises, call `announce()` (debounced inside `a11y.ts`).

## 6. Text mode (`renderers/text.ts`)

- **`resolveMode(host, mode)`:**
  - `'columns'` and `'text'` are honored on any element. `mode: 'columns'` on a form control keeps the 1.2 warning.
  - `'auto'` resolves to text for:
    - `input` with `type` in {text, search, tel, url, email, number} (an unknown type behaves as text);
    - `textarea`;
    - `option`;
    - SVG `text`, `tspan`, `textPath`.
  - `'auto'` resolves to unsupported (one-time warning, no writes) for `input` of any other type (hidden, checkbox, range, …), `select`, `img`, `video`, `audio`, `canvas`, `iframe`, `br`, `hr`, and **every SVG-namespace element other than `text`/`tspan`/`textPath`/`foreignObject`** (the SVG root, `g`, `a`, `rect`, …: HTML spans appended there never render; 1.2 warned for every SVG host and the `<g>` warning test stays).
  - SVG `foreignObject` resolves to columns (its HTML children render).
  - Every other element resolves to columns.
- **Writes** (only when the string changes):

  | host | per frame |
  |---|---|
  | `input[type=number]` | `el.value = fmt.numericText(round(fs.A))` (ASCII, no grouping or affixes) |
  | other text inputs, `textarea` | `el.value = fmt.text(round(fs.A), fs.ovf >= 0.5)` |
  | `option` | `el.text = …` (the visible label; `.value` is untouched. With no `value` attribute the submitted value follows the text, which is documented) |
  | SVG text, or any element in `mode:'text'` | the core owns one Text node. A host containing only text: that text is saved, replaced and restored on destroy. Otherwise the node is appended |

- **Motion:** the count path writes the per-frame text. The roll path is treated as count with roll timing. Events, Promise, trigger and live behave as in columns mode. `data-rn-state` is set on the host.
- **Never:** `defaultValue`, `input`/`change` events, role/aria/class. ngModel, v-model and React controlled inputs therefore never loop. README: "use read-only or uncontrolled inputs".
- The renderer receives the `Formatter` from the factory (and `setFormatter` on layout changes) and builds every string itself; the core never formats per frame. At rest it writes `RestState.numericText` (number inputs) or `RestState.text`.
- **Focus:**
  - `canAnimate()` returns `false` when the host is a form control and `host === host.getRootNode().activeElement`. The core then treats the change as instant (`animated: false` events in a microtask, §8.2 step 5) and calls `rest(target)`.
  - `rest()` on a focused control writes nothing and arms a one-shot `blur` listener. On blur it writes the final text only if `el.value` still equals the last string the renderer wrote; a user edit wins.
- **Destroy:** form controls keep the last value; text hosts get their saved text back.
- **The overlay is deferred** (§13).

## 7. Formatting and i18n (`format.ts`)

### 7.1 Path selection

- **Plain** (no `locale`, no `format`):
  - ASCII digits, `.` decimal, no grouping;
  - sign U+2212 in columns, ASCII `-` in labels and text;
  - `prefixText`/`suffixText`/`overflowSuffix` as static tokens.
  - With none of the 1.3 options set, the output, the label and the DOM are the 1.2 ones.
- **Intl:** strip unsupported keys (`notation`, `compactDisplay`, significant and fraction digits; one-time warning), then:

  ```js
  nf = new Intl.NumberFormat(locale, { ...format, notation: 'standard', minimumFractionDigits: f, maximumFractionDigits: f, minimumIntegerDigits: min(pad, 21) })
  ```

  - A `RangeError` on a string `useGrouping` → retry with `true`.
  - Any other construction error → plain path + warning.
- **f** = `decimals ?? (style = 'currency' ? min(20, new Intl.NumberFormat(locale, {style, currency}).resolvedOptions().maximumFractionDigits) : 0)`.

### 7.2 Tokens and layouts

- `layout(shape)` formats a representative number: `0` when `shape.zero` (so `signDisplay: 'exceptZero'` gets no sign token), otherwise sign × `10^(intDigits−1)`, with f zero fraction digits; `overflow` adds the `ovf` token. Then the parts are mapped:
  - `integer` chars → `i{j}` (from the right);
  - `fraction` → `f{j}`;
  - `group` → `g{j}` (j = place of the digit on its left);
  - `decimal` → `dec`;
  - `minusSign`/`plusSign` → `sign`;
  - `currency`/`unit`/`percentSign`/`literal` → static `lit:pre:n`/`lit:post:n` with a role.
- `prefixText` goes first, `suffixText` last, and `ovf` right after the last digit token.
- `pad > 21`: the extra zeros are prepended as digit tokens without separators.
- **`motionLayout(from, to)`** merges layouts by key in target order, inserting from-only tokens at their relative position. Presence is `both`, `enter` or `leave`. A token that is not a digit gets its tie from the first of these three diffs where it appears:
  1. `layout(from)` vs `layout(to.intDigits, from.negative, from.overflow)` → tie `{place: highest entering/leaving digit place}` (fixes crit-B M5 for `min2`);
  2. … vs `layout(to.intDigits, to.negative, from.overflow)` → tie `sign` (accounting parentheses, sign-side literals);
  3. … vs `layout(to)` → tie `overflow`.
- **Native digits:** `glyphs[d] = nf0.format(d)`, where `nf0` has the same locale and numbering system with grouping and fractions off. If any glyph is not a single code point, use ASCII.

### 7.3 Exact quantization

- **Intl path:** clamp `|v|` to `MAX_SAFE_INTEGER/(S·10^f)`, then `A = sgn·Number(concatenated integer+fraction digits of nfq.formatToParts(v))`, where `nfq` is a twin of `nf` with the same options plus `numberingSystem: 'latn'` and `useGrouping: false`. The parts of `nf` itself hold native digits for locales such as `ar-EG` ("١","٢٣٤") and `fa` ("۱۲۳"), for which `Number()` returns NaN (verified). Rounding comes from Intl (same rounding options), so text, label and columns agree.
- **Plain path:** `A = sgn(v)·round(|v|·10^f)`; with f = 0 this is the 1.2 `toDisplayInteger`.
- `A` is always a safe integer, so `String(A)` never uses exponents (fixes crit-A H7). `A = A || 0` normalizes −0.
- **Formatting always starts from A**, never from `v`: `text`, `labelText` and the SSR helpers format `A / 10^f / S` (normalized with `|| 0`). Intl prints `-0` for `-0` and for `-0.4` at 0 fraction digits (verified), while columns and 1.2 show `0`.

### 7.4 Label and overflow

- **Label:**
  - `resolveLabel` (in `format.ts`, shared by the core, `ssr.ts` and Vue `getSSRProps`) produces the default `formatter.labelText(value)`: unclamped, with affixes (for example "150" for a "99+" badge).
  - A string `label` replaces `{value}` with that text; a function gets `{ text, value, overflow }`.
  - The label is written to `aria-label` only when it changes. Columns mode only.
- **Overflow** shows `overflowSuffix` when `|A1| > Amax` and `overflowSuffix ≠ ''`. The sign is kept (`−99+`). With an empty `overflowSuffix` the behavior is exactly 1.2.
- **Compact notation:** not supported in columns or in 1.3 text mode (deferred).

## 8. Core behavior (`core.ts`)

### 8.1 State machine

```
idle ──setValue(animated, may run)──► moving ──settle──► idle
idle ──setValue(instant)──► idle      (microtask: rn-start, rn-end animated:false; promise resolves)
moving ──setValue(other target)──► moving   (new plan per §5.5/5.6; previous promises resolve completed:false)
moving ──setValue(same target, no explicit motion change)──► moving    (join)
moving ──setValue(same target, explicit instant)──► idle               (finish())
moving ──setValue(same target, explicit kind/duration/easing change)──► moving   (re-plan from the display)
idle|moving ──setValue while trigger='visible' ∧ not visible──► waiting (label updated now, display frozen)
waiting ──visible──► moving (from the display to the LATEST target)
any ──destroy──► dead (promises completed:false, no events, IO/live/ticker released)
```

### 8.2 `setValue(v, animate)` algorithm

1. Normalize `v`; `A1 = formatter.quantize(v)`; update `value` and the label. If dead: store the value and resolve `{ completed: false }`.
2. If `A1` is the in-flight target:
   - `animate` is `undefined`, or resolves to the in-flight kind with no explicit `duration`/`easing` → **join**: return the shared promise, no events.
   - An explicit instant request (`motion: 'none'`, `duration ≤ 0` in the call, or reduced motion / no rAF) → `finish()` and return its resolved promise. 1.2 jumped in the equivalent case.
   - An explicit kind change (e.g. `false` → roll while counting) or an explicit `duration`/`easing` → re-plan from the display (§5.5, no velocity carry across kinds); `rn-start` is not re-fired.

   If idle and `A1` is the displayed A: resolve `{ completed: true }` with no events.
3. `ensureStyles(host, opts.injectStyles)`.
4. If `trigger = 'visible'` and the host is not visible (`observeVisibility(...).visible !== true`, so the unknown state before the first IO callback counts as not visible): move to `waiting` and return a pending promise.
5. Resolve the timing kind (the full timing resolves in the read phase, §5.8; reduced motion and no-rAF are checked synchronously).
   - **Instant** ⇔ the synchronous part of `timing.instant` (§5.8) `|| !renderer.canAnimate()`: finish any motion, `renderer.rest(target)` (a focused text control defers that write to its guarded blur handler), then a microtask that dispatches `rn-start`/`rn-end` with `animated: false` and resolves promises.
   - A CSS-derived `D = 0` found in the read phase follows the read-phase rule of §5.8.
6. Otherwise, call `renderer.begin(motionLayout, kind, targetRest)` synchronously (collapsed entering nodes, pinned positions, roll-path `data-digit`). Mark the host animating and schedule the ticker.
7. Start a watchdog `setTimeout(D_estimate + 1000)`: if the same motion is still pending on rAF (background tab, `display:none` iframe), call `finish()`. Clear it on settle or retarget. It is not armed while `waiting`.

### 8.3 `from`, `trigger`, live, SSR adoption, update

- **`from`** (creation only): the first paint shows `quantize(from)` (no events), then an internal `setValue(value)` runs (events fire). Reduced motion or `from === value` shows `value` immediately.
  - The element records `fromConsumed` on its instance, so reconnecting (B39) never replays the intro. The same applies to `trigger`.
  - When an SSR fallback is adopted (a `[data-rn-ssr]` child or host), the intro is skipped and the first paint shows `value`, unless `trigger: 'visible'` and the host is not yet visible (then the user has not seen the server content, and the intro runs on visibility). Without this rule the on-screen content would regress value → from → value.
- **`trigger: 'visible'`:**
  - One `IntersectionObserver` per Document (threshold 0.25), observed for the core's lifetime, released on `destroy()`.
  - Until the first IO callback the state is unknown (`visible === null`) and counts as not visible, so a `from` intro or an early `setValue` waits for the first callback.
  - No IO support or no `defaultView` counts as visible (`cb(true)` synchronously).
  - Changing `trigger` via `update` observes or unobserves.
- **live:**
  - When `live ≠ 'off'`: `retainAnnouncer(host)`, and on every `rn-end` the core calls `announce(host, label, live)`. The 300 ms per-host debounce lives in `a11y.ts`, not in the core.
  - The region is a visually hidden `div[aria-live][aria-atomic=true][data-rn-live]` styled through CSSOM. There is one region per **container**: `container = host.closest('dialog,[aria-modal="true"]') ?? host.ownerDocument.body`, kept in a `WeakMap<Element, Region>`, created lazily, ref-counted by the hosts retained in it, and removed when its count reaches 0 or the container is disconnected (checked on each announce/release). Counters inside and outside a modal therefore never share a region.
  - Texts are cleared then set on the next task. Texts flushed in the same task are joined with ", ".
- **Adoption:** in columns mode, if the host has a direct child `[data-rn-ssr]`, it gets the `hidden` attribute (restored on destroy) and the columns are appended after it. The injected `.rn-ssr[data-rn-ssr][hidden] { display: none !important }` rule keeps it hidden against author `display` rules. A host carrying `data-rn-ssr` itself is treated as rendered by `renderStaticHTML` or Vue `getSSRProps`: `role`/`aria-label` count as core-owned (not recorded as previous values, removed on destroy) and the attribute is removed.
- **`update(o)`:** fields are applied through `normalizeField`.
  - A changed `LAYOUT_KEYS` field → `finish()` if moving, rebuild the formatter (and the renderer when the mode changes), then `rest()`.
  - `duration`/`easing`/`interpolate` → the next motion.
  - `label`/`live`/`trigger`/`injectStyles` → immediately.
  - `from` → ignored.
  - `value` last, through `setValue` (1.x order).
- **`render()`:** re-applies the host class and markers, re-checks style injection (cheap), and re-paints the current state.
- **destroy:** cancel ticker and watchdog, unobserve, release the announcer, `renderer.destroy()`, restore role/label/class (1.2), unhide the fallback, resolve promises `false`. Idempotent.

## 9. Style injection (`styles.ts`)

- **Config slot:** `globalThis[Symbol.for('rolling-number.config')]` (shared by the ESM and CJS copies), holding `{ injectStyles: true, nonce: null }`.
- **`ensureStyles(host, perInstance)`.** Return immediately if global or per-instance injection is off. Otherwise:
  1. `root = host.getRootNode()`. If it is neither a Document nor a ShadowRoot, use `host.ownerDocument` and re-check on the next `render()`/`setValue`.
  2. `doc = root.nodeType === 9 ? root : root.ownerDocument`; `view = doc.defaultView`. If `view` is null (`createHTMLDocument`, `DOMParser`, a detached iframe document), skip injection and re-check on the next `render()`/`setValue`.
  3. One sheet per **Document** (`WeakMap<Document, CSSStyleSheet>`), created with `new view.CSSStyleSheet()`. A constructed sheet can only be adopted in its constructor document (`NotAllowedError` otherwise); keying by Window was wrong because the WindowProxy survives same-origin iframe navigation. Shadow roots share their node document's sheet:
     - `replaceSync(layered ? '@layer rolling-number{' + RULES + '}' : RULES)`;
     - `layered = typeof view.CSSLayerBlockRule !== 'undefined'`.
  4. If `!root.adoptedStyleSheets.includes(sheet)`: `root.adoptedStyleSheets = [...root.adoptedStyleSheets, sheet]`. The `includes` check survives Lit/HMR reassignments.
  5. **Fallback** (no constructable sheets): `<style data-rn-style nonce=…>` prepended to `head` or to the ShadowRoot, once per root (WeakSet).
- **Cascade:**
  - Any unlayered author rule beats the layered copy, so `:root { --rn-duration: 1s }` keeps working.
  - An unlayered `dist/style.css` (identical rules plus the `:root` defaults) also wins harmlessly.
  - README: declare `@layer rolling-number;` first to put it lowest against Tailwind v4 layers.
- **CSP:** constructable sheets and CSSOM writes are allowed. The IIFE (`src/iife.ts`, WP5) auto-reads `document.currentScript.nonce` and `data-rn-inject="false"` and calls `configureRollingNumber` before `defineRollingNumber()`. All of that is guarded by `typeof document !== 'undefined'`, so importing the file in Node (smoke) defines the exports without throwing.
- **SSR safety:** no DOM at import time; injection runs only from the constructor and later calls.

## 15. Changelog of spec review

Revision 2 resolves the implementation-readiness review (37 findings: 17 major, 20 minor; duplicates merged). Nothing in the public API became breaking; one new sign-off row (S6) documents an existing consequence of the design.

- **Compatibility shims (WP0 exit).** `RN_DEFAULTS`/`normalizeOptions` stay in `core.ts` with the exact 1.2 shapes; the new names are `RN_DEFAULTS_13`/`resolveOptions` in `options.ts`. WP0 may create hand-over stubs (`action.ts`, `iife.ts`, `smoke-manifest.mjs`) and make type-only edits to the element/adapters (§2.3, §3.1, §3.2, §3.3).
- **Contracts.** Renderer factory receives the `Formatter` (+ `setFormatter`); `frame(fs)` without text; the text renderer builds strings itself (`overflow = ovf ≥ 0.5`); `RestState.numericText`; `canAnimate()`; owned nodes absent from a motion layout are removed only by `rest()`; `Token.place` = k with the i/f mapping and an example; `LayoutShape.zero`; `Formatter.shapeOfDisplay` for retargets; `resolveLabel` moved to `format.ts`; `OPTION_ATTRIBUTES`; `getResolved(core)`; `observeVisibility` returns `{ stop, visible }` with an unknown-initial state; announcer debounce owned by `a11y.ts`; ticker cancel rule (§3.3).
- **Unset timing everywhere (S5).** The element and the Angular directive pass `null` for absent `duration`/`easing`; getters keep returning 400 (§2.5, §2.6).
- **Ownership/infra.** `vitest.config.ts` (with `test.css.include`, verified), `tests/tsconfig.json` (excludes `tests/visual`), devDependencies (`esbuild`, `@playwright/test@1.64`, `vue-tsc`) → WP0; `iife.ts` → WP5 with a listed global and a `typeof document` guard; smoke split (`expectedExports` WP0, `smoke-manifest.mjs` WP7); `tests/ssr.test.ts` → WP2; append-only `tests/helpers.ts`; per-adapter `*.test-d.ts`; Vue SFC fixture + `check:vue-types` (§3.1, §3.2, §10, §11).
- **WP0 core stub behavior** for promises/events specified so adapter tests survive WP6 (§3.2).
- **Engine math.** Count plans clamp `q` to [0, 1] (overshooting easings no longer escape [A0, A1] or flash a sign); `sigma ≡ 0` with no negative endpoint; retarget `ΔA` uses the clamped target with a `ΔA≈0`/`v=0` guard (§5.1, §5.4, §5.6).
- **Timing.** `kind` follows `interpolate` for option objects without `motion`; a CSS `0s` duration disables only rolls (count keeps 400; S4 updated); read-phase instant rule with `animated:false` events in that frame (§5.8, §2.4).

Partially adopted (with reason):
- *Join on `setValue(target, false)` while counting* — the review asked for `finish()`. In 1.3 `false` means "roll", so the call re-plans as a roll from the display. That is the 1.3 equivalent of 1.2's behavior, where the DOM jumped and CSS rolled the columns. Only `motion: 'none'` / `duration: 0` finish instantly.
- *WP0 stub `rn-start` timing* — the review suggested a microtask for every `setValue`. The stub dispatches animated `rn-start` in the first rAF, as WP6 will, so adapter tests do not change when WP6 lands.
- *Overshoot clamp* — implemented as `q = clamp(E(p), 0, 1)` for count plans. This is equivalent to clamping A to [min(A0,A1), max(A0,A1)], and it also bounds reels and the remap offset. Roll plans keep the bounce.

Rejected: none.
