rolling-number

An animated, odometer-style number counter. Zero dependencies, one API for the Web Component, vanilla JS, React, Vue, Angular and Svelte — and it works inside any element: text, buttons, table cells, inputs, textareas and SVG.

npm i rolling-number Styles are injected automatically: no CSS import needed.

Works in any elementspan · button · td · input · textarea · option · svg

      
The same counter attaches to whatever element you already have. Containers get animated digit columns; form fields, <option> and SVG text are animated as text, so the value stays a normal value (read-only or uncontrolled fields are recommended).
