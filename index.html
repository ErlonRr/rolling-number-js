Rolling Number

An animated, odometer-style number counter. Give it a value and it rolls there — inside any element: text, buttons, table cells, inputs, textareas and SVG.

🎰

Continuous odometer

Counts through the values in between; fast digits spin as reels, 9 → 0 always rolls forward, and a new value mid-animation continues from what is on screen.

🧩

Any element

Digit columns inside containers; animated text inside inputs, textareas, options and SVG text. Your other children are never touched.

🌍

Real number formatting

Currencies, percent, units, locales and native digits through Intl, plus 99+ badges, prefixes and suffixes.

📡

Events & promises

rn-start / rn-end events everywhere, and setValue() resolves when the animation ends.

♿

Accessible

An accessible name with the real value, optional live announcements, and instant changes under reduced motion.

🧠

Typed, SSR-ready, styles included

Typed options in every IDE, server-rendered fallbacks, and a stylesheet injected automatically (CSP-friendly).

Installation & quick start

Install the package; the stylesheet is injected automatically the first time a counter is created.

Events & promises

          
Every change fires rn-start and rn-end on the host (they bubble), and setValue() returns a promise that resolves when the animation ends.

        

        

          

            
            

              
              
              
              
            

          

          
Events (rn-start / rn-end)

        

        
const counter = document.querySelector('rolling-number');

counter.addEventListener('rn-start', (e) => console.log('start', e.detail));  // { value, from, animated }
counter.addEventListener('rn-end', (e) => console.log('end', e.detail.value));

const { completed } = await counter.setValue(500);   // true when it reached 500
counter.setValue(10, false);                          // roll each digit
counter.setValue(10, { motion: 'none' });             // instant
counter.setValue(10, { duration: 1500, easing: 'ease-out-expo' });

// React: onRnStart / onRnEnd · Vue: @rn-start / @rn-end · Angular: (rnStart) / (rnEnd)

Options

          
Every option is optional and works the same way in every integration. Invalid input never throws: it falls back to the default.

        

        

          

            
OptionAttributeDefaultWhat it does

            
              
valuevalue0The number to show, rounded to the displayed precision.

              
padpad1Minimum integer digits, padded with zeros (1–64).

              
maxmaxnullDisplay limit, e.g. 99 for a badge; the accessible label keeps the real value.

              
overflowSuffixoverflow-suffix''Shown after the digits above max: '+' → 99+.

              
interpolateinterpolate, no-interpolatetruetrue counts through the values; false rolls each digit straight to its new digit.

              
durationdurationautoAnimation length in ms (auto: 400 when counting, --rn-duration when rolling).

              
easingeasingautoA preset (odometer, ease-out-expo, …), a CSS easing or a function.

              
decimalsdecimalsautoFixed fraction digits (0–20); auto = the currency's digits, else 0.

              
localelocale—BCP 47 locale, e.g. 'de-DE'; turns on Intl formatting.

              
formatformat (JSON)—Intl options: currency, percent, unit, signDisplay, useGrouping, numberingSystem.

              
prefixTextprefix-text''Static text before the number.

              
suffixTextsuffix-text''Static text after the number.

              
modemode'auto''columns' or 'text'; auto picks text for form fields and SVG text.

              
fromfrom—Value shown at creation, then the counter animates to value.

              
triggertrigger'immediate''visible': animations wait until the counter is on screen.

React and Vue: props. Angular: rollingNumber (the value), pad, max, interpolate, duration, and rn + the option name for the others (rnFormat, rnLocale, …). update(): undefined = unchanged, null = back to the default.

      


      
      

        

          
API & events

          
const core = new RollingNumberCore(element, options) — the element and every framework binding wrap this class.

        

        

          

            
MethodDescription

            
              
setValue(value, animate?)Sets the target; returns Promise<{ value, completed }>. animate: true (count), false (roll) or { motion, duration, easing }.

              
update(options)Changes several options (undefined = unchanged, null = default).

              
whenSettled()Promise for the current animation (resolved at once when idle).

              
finish()Jumps to the target now.

              
getValue() / getDisplayValue()The target / the value on screen.

              
getText()The formatted target text, e.g. "99+".

              
isAnimating()true while the display moves.

              
destroy()Removes only the counter's nodes and restores the element.

            
          

        

        

          

            
EventWhen

            
              
rn-startThe display starts moving (also instant changes, with animated: false). detail = { value, from, animated }.

              
rn-endThe display settled on the final value; the DOM is final.

            
          

        

        

          

            
FunctionDescription

            
              
rollingNumber(node, param)Action for Svelte, Solid, Alpine, Lit: { update, destroy, core }.

              
configureRollingNumber({ injectStyles, nonce })Global configuration (call before the first counter).

              
injectRollingNumberStyles(root)Adds the stylesheet to a document or shadow root yourself.

              
renderStaticText() / renderStaticHTML()Server-side rendering helpers (also in rolling-number/ssr).

              
defineRollingNumber(tagName?)Registers the element under another tag name.
